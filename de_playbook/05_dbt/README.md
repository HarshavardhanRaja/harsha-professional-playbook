# 05_dbt — Study Guide

## 📋 What's in this module
Modern data transformation workflow with dbt (data build tool), modular modeling, materializations, testing, snapshots, and production projects.

## 📚 Study Order
1. dbt Fundamentals — dbt CLI, project layout, profiles.yml, dbt_project.yml, ref() and source() functions
2. Models and Materializations — View, Table, Ephemeral, Incremental materializations, Jinja templating, custom macros
3. dbt Testing — Generic tests (unique, not_null, accepted_values, relationships), singular SQL tests, dbt-expectations package
4. Incremental & Snapshots — Incremental strategies (merge, append, delete+insert), dbt Snapshots for tracking history
5. dbt Hands-on Project — End-to-end dbt project design, CI/CD with dbt Cloud/Core, dbt docs generation
