# 04_Data_Warehousing — Study Guide

## 📋 What's in this module
Data warehouse design principles, Kimball dimensional modeling, Slowly Changing Dimensions (SCD), Change Data Capture (CDC), and incremental loading patterns.

## 📚 Study Order
1. DWH Core Concepts — OLTP vs OLAP, Data Warehouse vs Data Lake vs Data Lakehouse architectures
2. Dimensional Modeling — Fact tables, Dimension tables, Star schema, Snowflake schema, Factless facts, Grain definition
3. SCD Types — SCD Type 0, 1, 2, 3, 4, 6 implementations and SQL update queries
4. CDC Patterns — Change Data Capture mechanisms (Log-based, Query-based, Trigger-based), Debezium
5. Incremental Loading — High watermark pattern, upsert/merge logic, idempotency, append-only strategies
