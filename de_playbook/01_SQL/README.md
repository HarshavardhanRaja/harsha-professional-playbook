# 01_SQL — Study Guide

## 📋 What's in this module
Master SQL querying, window functions, CTEs, complex joins, aggregations, and data engineering specific analytical patterns.

## 📚 Study Order
1. SQL Foundations — Basic SELECT, WHERE filtering, HAVING, and SQL logical execution order
2. Joins — Inner, Left, Right, Full Outer, Cross, Self Joins and NULL handling
3. Aggregations — GROUP BY, COUNT DISTINCT, GROUPING SETS, CUBE, and ROLLUP
4. Window Functions — ROW_NUMBER, RANK, DENSE_RANK, LEAD, LAG, running totals, and frame clauses
5. CTEs and Subqueries — With clauses, recursive CTEs, and correlated subqueries
6. Analytical Patterns — User retention, churn, funnel analysis, and sessionization patterns
7. DE SQL Patterns — Deduplication, Gaps & Islands, SCD query patterns, and incremental merge queries

1 Week (7 Days)
