# 03_PySpark — Study Guide

## 📋 What's in this module
Distributed data processing using PySpark DataFrames, Spark SQL, partitioning strategies, joins, and performance optimization.

## 📚 Study Order
1. PySpark Fundamentals — Spark Architecture, Driver/Executors, RDD vs DataFrame, Catalyst Optimizer, Tungsten
2. DataFrame Operations — Transformations vs Actions, Lazy Evaluation, select, filter, withColumn, native spark functions vs UDFs
3. PySpark Joins — Broadcast Hash Join, Shuffle Hash Join, Sort Merge Join, handling skewed keys
4. PySpark Window Functions — Window.partitionBy, orderBy, rowsBetween, rangeBetween, lead, lag, running metrics at scale
5. Partitioning & Shuffling — repartition vs coalesce, partitionBy, bucketing, managing shuffle partitions
6. PySpark Optimization — AQE (Adaptive Query Execution), caching & persisting, spill to disk, memory fraction configuration
