# 06_Databricks — Study Guide

## 📋 What's in this module
Databricks Unified Platform, Delta Lake transaction protocol, Medallion Architecture (Bronze/Silver/Gold), Auto Loader, and Lakehouse optimization.

## 📚 Study Order
1. Delta Lake — ACID transactions, Delta log (_delta_log), Parquet files, time travel, OPTIMIZE and Z-ORDER
2. Medallion Architecture — Bronze (raw ingestion), Silver (cleaned/transformed), Gold (aggregated analytics) layers
3. Auto Loader — cloudFiles stream ingestion, schema inference, schema evolution, checkpointing
4. Databricks Optimization — File compaction, Liquid Clustering, disk caching, Delta Live Tables (DLT)
5. Databricks Hands-on Project — End-to-end Medallion pipeline build using PySpark and Delta Lake on Databricks
