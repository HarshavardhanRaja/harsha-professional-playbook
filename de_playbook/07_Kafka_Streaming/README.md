# 07_Kafka_Streaming — Study Guide

## 📋 What's in this module
Real-time stream processing with Apache Kafka, consumer groups, delivery semantics, and integration with PySpark Structured Streaming.

## 📚 Study Order
1. Kafka Fundamentals — Topics, Partitions, Replicas, Brokers, Producers, Consumers, Consumer Groups, Offsets
2. Delivery Guarantees — At-most-once, At-least-once, Exactly-once processing, Idempotent producers, Transactional APIs
3. Kafka with PySpark — PySpark Structured Streaming with Kafka source & sink, watermarking, windowed aggregations
4. Kafka Streaming Project — End-to-end real-time pipeline (Kafka producer -> Spark Structured Streaming -> Delta Lake sink)
