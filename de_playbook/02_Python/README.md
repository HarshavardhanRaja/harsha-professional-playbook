# 02_Python — Study Guide

## 📋 What's in this module
Deep dive into core Python, data structures, object-oriented programming, iterators, decorators, concurrency, and data engineering coding patterns.

## 📚 Study Order
1. Data Structures — Lists, dicts, sets, tuples, collections (defaultdict, Counter, deque), time/space complexity
2. Functions & Scope — Args, kwargs, LEGB rule, lambda functions, and closures
3. OOP — Classes, inheritance, polymorphism, dunder methods, dataclasses, and abstract base classes
4. Generators & Iterators — Yield, iterators, generator expressions, memory efficiency with large data streams
5. Decorators — Function decorators, parameterized decorators, retry logic wrappers, execution timing
6. Concurrency — Multiprocessing, multithreading, GIL, asyncio, and parallel data processing
7. Error Handling — Custom exceptions, try/except/else/finally, context managers (with statement)
8. Coding Patterns — Two pointers, sliding window, hashmap indexing, string parsing, tree/graph algorithms for DE

1 Week (7 Days)
