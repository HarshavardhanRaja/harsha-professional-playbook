# Hadoop vs Spark

## Hadoop

- Built around HDFS and MapReduce.
- Strong for batch processing.
- Writes intermediate results to disk frequently.

## Spark

- General-purpose distributed compute engine.
- Supports batch, SQL, machine learning, graph processing, and streaming.
- Uses in-memory execution where possible.

## Key Difference

Spark is usually faster and more flexible for iterative and interactive workloads, while Hadoop introduced the foundational distributed storage and batch processing model.
