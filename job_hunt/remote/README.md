# 🌐 Remote Job Hunt

This folder tracks all remote Data Engineering job findings — leads, applications, and outcomes.

## 📁 Folder Structure

```
remote/
├── README.md               ← This file (overview + instructions)
├── tracker.md              ← Master job tracker (active pipeline)
├── platforms.md            ← Platform notes & search strategies
└── leads/                  ← One file per promising company/role
```

## 🔍 Search Filters to Use

| Platform | Filter Strategy |
|---|---|
| LinkedIn | Remote · Data Engineer · Worldwide · Posted: 24–48hrs |
| Turing.com | Apply once → passive matching |
| Toptal | Vetting pipeline → apply separately |
| We Work Remotely | Data/Analytics category |
| Wellfound | Remote · Full-time · Data Engineer |
| Greenhouse (Google) | `site:greenhouse.io "data engineer" "remote"` |

## ✅ Criteria for a Good Remote Role (India)

- [ ] Explicitly says "Worldwide" or "APAC welcome" or "async-first"
- [ ] No "US timezone required" or "W-2 only" clauses
- [ ] Clear async communication culture (Notion, Loom, async standups)
- [ ] Pays in USD/EUR
- [ ] Stack overlaps with your skillset
